## 摘要
我们提出了Echo Infinity，一种面向实时无限视频生成的自回归（AR）框架，它采用可学习的演化记忆，以恒定成本动态过滤、抽象和压缩任意长度的历史信息。现有方法主要使用预定义的KV缓存调度、固定比例启发式压缩或推理时的RoPE适配来管理记忆。这些设计由于有限的缓存窗口和忽视自回归生成噪声，不可避免地丢失历史信息并放大复合误差。受人类记忆巩固的启发，Echo-Infinity用可学习的记忆查询替代了手工设计的记忆管理，这些查询在过去的帧从局部窗口中逐出时，通过注意力和门控机制进行更新。查询与视频扩散变换器（DiTs）进行端到端优化，形成一种演化记忆，支持任意压缩比，且计算量恒定，与视频长度无关。它们还充当可泛化的生成先验，即使仅使用优化后的初始状态也能提升质量。我们进一步引入了统一相对RoPE方案，它将汇点帧锚定在ID 0开始，并让最新帧ID在整个训练和推理过程中最多增长到DiTs预训练的最大时间RoPE ID，从而将模型从有限RoPE约束中解放出来，并缩小训练-测试的RoPE外推差距。在长视频和短视频生成中，Echo-Infinity达到了最先进的性能，并且据我们所知，首次展示了有前景的24小时（>130万帧）实时展开，为无限视频生成指明了一条实用路径。

## Abstract
We present Echo Infinity, an autoregressive (AR) framework towards real-time infinite video generation that employs a learnable evolving memory to dynamically filter, abstract, and compress any-length history at constant cost. Existing methods mainly curate memory with predefined KV-cache schedules, fixed-ratio heuristic compression, or inference-time RoPE adaptation. These designs inevitably lose historical information and amplify compounding errors due to their limited cache window and ignorance of autoregressive generation noise. Inspired by human memory consolidation, Echo-Infinity replaces handcrafted memory curation with learnable Memory Query, which are updated by attention and a gating mechanism when past frames are evicted from the local window. The queries are optimized end-to-end with the video diffusion transformers (DiTs), forming an evolving memory that supports arbitrary compression ratios with constant computation independent of video length. They also act as a generalizable generation prior, improving quality even when only the optimized initial state is used. We further introduce Unified Relative RoPE Recipe, which anchors the sink frames to start from id 0 and lets the newest frame id grow at most to the DiTs' pretrained maximum temporal RoPE id throughout training and inference, freeing the model from the finite RoPE constraint and closing the train-test RoPE extrapolation gap. In long and short video generation, Echo-Infinity achieves state-of-the-art performance, and, to our knowledge, demonstrates promising 24-hour (>1.3 M frames) real-time rollouts for the first time, suggesting a practical path toward infinite video generation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的实时无限视频生成方法（如自回归扩散Transformer）面临两大瓶颈：
  1. **无界KV缓存增长**：随着视频长度增加，历史帧的键值（KV）缓存线性增长，导致内存爆炸。
  2. **时间RoPE外推失效**：预训练的Transformer中时间位置编码（RoPE）仅支持有限索引（如最大20），超出后导致质量崩溃或溢出。
- **现有方法的不足**：目前解决方法（窗口截断、手工KV缓存管理、启发式压缩）均存在局限性：
  - 窗口截断直接丢弃历史信息，损失长程一致性。
  - 手工规则（如文本检索）依赖离线设计，无法适应生成噪声。
  - 固定压缩比仍会导致内存随视频长度增长，或需动态调整压缩比，加剧误差累积。
- **整体含义**：受人类记忆分层巩固机制启发，论文提出一种**可学习的演化记忆**，通过端到端优化自动过滤、抽象、压缩历史信息，并以恒定内存开销支持任意长度视频的实时生成，首次实现24小时（>130万帧）的实时滚动，为无限视频生成提供实用路径。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 用**可学习的Memory Query**替代手工记忆管理，模仿人类记忆的三层结构：汇点帧（长期锚点）、局部窗口（工作缓冲）、演化记忆查询（长期记忆）。
- Memory Query通过注意力与门控机制动态更新，对逐出窗口的历史KV进行过滤、抽象和压缩，保持固定大小。
- 引入**统一相对RoPE方案**，在训练和推理中保持所有活跃时间索引在预训练范围内，消除外推问题。

### 关键技术细节

#### 记忆查询（Memory Query）
- **定义**：一组可学习的查询令牌 Q ∈ ℝ^{1×N_Q·S×d}（N_Q=3个记忆帧，S=1560令牌/帧），与视频DiTs端到端优化。
- **更新机制（图3b）**：
  - 当局部窗口滑动，一组帧被逐出时，其KV缓存（{K_evict, V_evict}）输入编码器Encoder（L_enc=2层交叉注意力）。
  - 获得候选查询 ̃Q，通过sigmoid门控残差更新：g = σ([Q; ̃Q]W_gate)，Q ← g⊙Q + (1−g)⊙̃Q。
  - 门控控制信息覆盖，实现选择性记忆巩固。
- **注入方式**：在每层DiT注意力中，Memory Query被投影为K_Q/V_Q，与汇点KV、局部KV拼接，作为插件式键值源，不改变主干结构。
- **训练**：在第一阶段（5秒训练）与DMD损失联合优化；第二阶段长视频微调时，仅跨子片段边界分离梯度，内部继续优化。

#### 统一相对RoPE方案
- **问题**：绝对RoPE在推理时索引超出训练范围（如超过20），导致外推失败。
- **方案**：
  - 训练和推理使用相同相对RoPE策略：汇点帧始终从ID 0开始；最新帧ID增长至预训练最大值f_max后，后续帧ID回绕（旋转），所有活跃ID始终在[0, f_max]内。
  - 分为**增长阶段**（从汇点结束到f_max）和**成熟阶段**（恒定在f_max，新块生成时旧帧ID平移）。
- **算法流程**（Algorithm 1）：每块生成步骤包括：
  1. 计算相对RoPE ID分配（式3）。
  2. 若已有历史，将Memory Query投影为K_Q/V_Q并应用RoPE。
  3. 三层注意力：汇点+记忆+局部+当前块。
  4. 逐层执行因果注意，生成新帧。
  5. 更新局部窗口：追加新KV，若超出窗口则逐出旧KV。
  6. 如果有帧被逐出，执行Memory Query更新（式4），设置has_history标志。

- Echo-Infinity在长视频（30s/240s）、短视频（5s）、交互式（60s）生成上均达到最先进水平，用户偏好显著优于基线（30s：59.53% vs 14.73%；240s：71.67% vs 14.13%）。
