## 摘要
大语言模型在自回归推理过程中速度较慢。虽然自推测解码可以加速这一过程，但其效率受到静态配置（如固定的退出层和推测长度）的限制。我们将这一优化问题重新表述为马尔可夫决策过程，并提出LEDE，一个使用离线强化学习的框架。LEDE学习一个策略，根据每一步生成序列的局部上下文动态选择最优的退出层和推测长度，从而平衡计算成本和草稿质量。在Llama-2和Llama-3模型上的全面评估表明，与自回归解码相比，LEDE实现了高达2.0倍至2.7倍的加速，并且相比静态推测基线额外提供了17%的加速。

## Abstract
Large Language Models suffer from slow autoregressive inference. While self-speculative decoding accelerates this process, its efficiency is hampered by static configurations like fixed exit layers and speculation lengths. We reframe this optimization as a \textbf{Markov Decision Process} and propose \textbf{LEDE}, a framework that uses offline reinforcement learning. LEDE learns a policy to dynamically select the optimal exit layer and speculation length based on the local context of the generated sequence at each step, balancing computational cost and draft quality. Comprehensive evaluations on Llama-2 and Llama-3 models show LEDE achieves up to a $2.0\times$$\sim$$2.7\times$ speedup over autoregressive decoding and and provides an additional 17\% speedup over the static speculative baselines.

## 1. 核心问题与整体含义（研究动机和背景）

大语言模型（LLMs）具备强大的能力，但其自回归推理过程缓慢，因为每个 token 都必须通过全部 Transformer 层。**自推测解码（Self-Speculative Decoding, SSD）** 利用模型的浅层作为内部草稿模型并行生成候选 token，然后由完整模型验证，从而加速推理。然而，现有 SSD 方法采用**静态配置**（固定的退出层和固定的推测长度），这无法适应不同 token 的预测难度。事实上，LLM 推理存在上下文稀疏性——并非所有 token 都同样难以预测。静态配置导致计算与草稿质量之间的次优平衡，制约了加速效果。本文的核心问题即：**如何根据上下文动态选择最优的退出层和推测长度，以最大化推理效率**？

整体含义：本文首次将 SSD 中退出层和推测长度的动态控制建模为**马尔可夫决策过程（MDP）**，并利用**离线强化学习（Offline RL）** 训练策略网络，实现了自适应的、经验驱动的动态退出，显著提升了多种模型和任务上的推理速度。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
将 SSD 的退出决策重新表述为顺序决策问题，训练一个**深度 Q 网络（DQN）**，在每个候选层观察模型内部状态，决定“继续”或“退出”。该决策不仅决定退出层，还通过相同的策略自适应控制草稿长度，实现**双控（dual-control）**。

### 关键技术细节

#### （1）马尔可夫决策过程（MDP）定义

- **状态空间** \( s_l \)：在候选层 \( l \)，从模型输出分布中提取三个特征：
  - **Token Confidence** \( C_{lk} \)：top-5 token 的平均负对数概率。
  - **Token Entropy** \( H_l \)：输出分布的熵。
  - **Average Trace of Token Confidence** \( C_{\text{trace}} \)：最近 T=20 步内 top-1 预测的平均负对数概率。
- **动作空间** \( a_t \in \{\text{continue}, \text{exit}\} \)：continue 进入下一候选层，exit 将当前层设为退出层 \( l^* \)。
- **奖励函数** \( R \)：综合正确性、效率和深度惩罚。
  - 若退出且草稿 token 被接受：\( R = 1 + (L - l^*)/L \)。
  - 若退出但草稿 token 被拒绝：\( R = -2 + (L - l^*)/L \)。
  - 若继续：\( R = -0.01 \)。
- 目标：最大化累积折扣奖励。

#### （2）离线强化学习训练

- 使用**因子化高斯噪声线性层**进行探索，初始 σ₀=0.1。
- 经验回放缓冲区：先进行 200 个 episode 的探索填充缓冲区。
- 每 4 步学习一次，mini-batch 大小 32。
- 使用 **n-step TD 误差**（n=3）更新 Q 网络，目标网络每 512 步更新一次。
- 优化器：Adam，学习率 \(6.25 \times 10^{-5}\)。

#### （3）动态推理过程

- **第一轮**：在前向传播中逐层调用策略，确定退出层 \( l^* \)（图 1b）。
- **草稿生成阶段**：在 \( l^* \) 层开始生成草稿 token。每生成一个 token 后重新评估状态：若动作“exit”则继续草稿（表示高置信度）；若动作“continue”则立即终止草稿并进入验证（图 1c）。从而自适应调整草稿长度。

## 6. 主要结论与发现

- **LEDE 在所有测试场景下均优于静态和基于规则的自适应方法**：平均加速比 2.32×，最高 2.72×；相比静态基线（LayerSkip）额外提升 17%。

- **策略网络能够有效学习退出时机**：训练过程中接受率稳定于 ~0.9，平均退出层在约 7 层左右收敛，说明代理学会了平衡计算深度与草稿质量。

## 7. 优点

- **问题建模创新**：首次将 SSD 的退出层和草稿长度选择统一建模为 MDP，并用离线 RL 求解，打破了静态配置的局限。
- **状态设计简洁有效**：仅利用模型内部概率分布的三个统计量作为状态，无需额外特征。
- **双控机制**：一次决策同时优化“退哪里”和“写多长”，实现计算资源的精细分配。
- **离线学习**：利用离线经验回放训练，避免了在线强化学习的高成本交互；且训练完成后推理时无额外开销（仅有小 MLP 前向）。
- **实验覆盖全面**：从 1B 到 34B 模型、多任务验证，消融实验清晰。
