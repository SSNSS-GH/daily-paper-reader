## 摘要
扩散大语言模型（dLLM）通过迭代式并行揭蔽和修正多个位置来生成响应。这一过程留下了丰富的去噪痕迹，描述了哪些词元变得确定、哪些仍不稳定以及承诺何时形成。现有的dLLM强化学习方法仅弱化地利用这一信号。扁平展开成本低廉，但将单一的结局奖励分配给整个轨迹。树形展开通过分支部分轨迹并将叶节点奖励向上传播，提供了更精细、可验证的训练信号，但计算密集。我们探究去噪痕迹本身是否能在不增加树级计算的情况下提供类似树的监督。我们提出CAPR（缓存摊销路径细化），一种dLLM-RL算法，它将去噪痕迹总结为紧凑的路径状态，利用缓存的轨迹状态生成廉价的兄弟延续，并训练块级价值头用于局部块级监督。在按块揭蔽调度下，CAPR记录路径状态和块进度特征，然后根据每个块中揭示的词元将最终结局奖励重新分配给各块。这训练价值头将单个稀疏奖励转化为块级PPO权重。因此，CAPR恢复了许多树搜索的粒度，同时避免了完整的树展开，在标准设置下将展开生成成本降低至扁平展开的约0.75倍、树形展开的0.6倍。在4x4数独、倒计时、GSM8K和Math500上，基于密集和混合专家LLaDA骨干网络，CAPR在256和512词元预算下为RL调优的dLLM设立了新的最优结果。在数独任务上，它以不到每步计算量三分之一的代价匹配了最强的树形结构基准。

## Abstract
Diffusion large language models (dLLMs) generate responses by iteratively unmasking and revising many positions in parallel. This process leaves a rich denoising trace depicting which tokens become confident, which remain unstable, and when commitments form. Existing dLLM reinforcement learning methods use this signal only weakly. Flat rollouts are cheap, but assign a single outcome reward to the whole trajectory. Tree rollouts provide finer, verifiable training signals by branching partial trajectories and propagating leaf rewards upward, but are compute intensive. We ask whether the denoising trace itself can provide tree-like supervision without tree-level compute. We introduce CAPR (Cached-Amortized Path Refinement), a dLLM-RL algorithm that summarizes the denoising trace into a compact path state, uses cached trajectory states to generate cheap sibling continuations, and trains a block-level value head for local block-wise supervision. Under a block-wise unmasking schedule, CAPR records path-state and block-progress features, then redistributes the final outcome reward across blocks according to the tokens revealed in each block. This trains the value head to convert one sparse reward into block-level PPO weights. CAPR therefore recovers much of the granularity of tree search while avoiding full tree expansion, reducing rollout-generation cost to roughly 0.75x that of flat rollouts and 0.6x that of tree rollouts (under standard settings). Across 4x4 Sudoku, Countdown, GSM8K, and Math500, on dense and mixture-of-experts LLaDA backbones, CAPR sets a new state of the art for RL-tuned dLLMs at 256- and 512-token budgets. On Sudoku, it matches the strongest tree-structured baseline at less than one third of the per-step compute.

## 1. 论文的核心问题与整体含义

扩散大语言模型（dLLM）通过迭代去噪生成文本，每一步都暴露所有被遮蔽位置的预测分布，形成丰富的**去噪轨迹**（denoising trace），记录了哪些词元逐渐确定、哪些仍在震荡。然而，现有的基于强化学习（RL）的后训练方法对这一信号利用不足：

- **扁平（flat）rollout** 方法（如 Diffu-GRPO）廉价但将同一结局奖励分配给所有去噪步，无法区分关键决策；
- **树（tree）rollout** 方法（如 d-TreeRPO）通过分支比较获得精细优势，但计算成本随分支因子和深度急剧增长。

本文的核心问题是：**能否直接利用去噪轨迹本身提供类似树形搜索的粒度监督，而无需展开完整树？** 答案是一套名为 CAPR（Cached-Amortized Path Refinement）的算法，它将去噪轨迹压缩为路径状态，训练块级价值头，以远低于树方法的花费实现块级优势分配。

## 2. 方法论

### 核心思想
CAPR 包含三个相互配合的机制，将去噪轨迹转化为可重用的训练信号，并在平展 rollout 与树 rollout 之间取得高效折中。

### 关键技术细节

1. **Cache & Steer（缓存与引导）**
   - 每一步记录每个位置的**置信度**（当前最高概率）、**稳定性**（最高概率词元是否与上一步相同）、**归一化熵**和**确定度**，组成特征向量 \(\phi_j^{(t)}\)。
   - 通过 GRU 样式的 PathGRU 更新得到紧凑的**路径状态** \(h_j^{(t)}\)，正值表示该位置已稳定承诺，负值表示仍在震荡。
   - 路径状态用于**引导下一步去噪**：
     - 对 logits 施加偏置：稳定位置获得正偏置，震荡位置被抑制；
     - 指导哪些遮蔽位置应该被揭示或重新遮蔽：计算综合得分 \(\kappa_j^{(t)}\)，根据去噪调度选取 Top-k 位置进行揭蔽。

2. **Branch & Prune（分支与剪枝）**
   - 在去噪轨迹的中点（\(f_b=0.5\)）缓存前缀状态，然后分支出 \(G_b=2\) 个**兄弟延续**（通过 Gumbel 扰动同一前缀的 logits 采样不同后续）。
   - 分支完成后，以固定的调度频率根据分支的平均路径状态（承诺程度）**剪枝**低质量分支，仅保留最有希望的部分。
   - 这种设计避免展开完整树：一个分支组仅需 \((f_b + G_b(1-f_b))N\) 次前向传播，是平展 rollout 的 0.75 倍，树 rollout 的 0.6 倍。

3. **Block Critic（块级评论家）**
   - 在**块边界**（每块长度 32 词元）记录紧凑状态：包含路径状态统计（均值、标准差）、块内剩余遮蔽比例、提示级奖励统计、已揭蔽词元嵌入等。
   - 使用 TD/GAE 将最终稀疏奖励转化为**每个块的单独优势** \(\hat{A}_b\)，用于加权 PPO 更新中的 rollout 级优势。
   - 价值头通过 Polyak 平均保持稳定，并设有**校准门控**：当价值头损失升高时，自动降低块级信号权重，平滑退化到平展 GRPO。

4. **辅助损失**
   - **自蒸馏损失**：将已求解 rollout（奖励为满分的组）作为监督信号，通过交叉熵损失强化政策。其权重随求解组比例动态增长。
   - **单侧卡方正则化**：针对 token 级 log-ratio 的正向尖峰进行惩罚，防止少数高概率 token 主导梯度，避免不稳定。

### 算法流程概要
对每个提示：
1. 执行 \(M\) 组去噪，每组共享前缀并在中点分支 \(G_b\) 条兄弟，剪枝低质量分支，最终收集 \(G\) 条完整 rollout。
2. 用验证器计算每条 rollout 的结局奖励。
3. 对每个块计算块级奖励，用 TD/GAE 得到块优势。
4. 通过校准门控混合块优势与原始 GRPO 优势。
5. 用组合损失（PPO + KL + χ² + 自蒸馏 + 价值头 MSE）更新政策和价值头，并慢更新目标价值头。

## 6. 主要结论与发现

1. **性能领先**：在 256 词元预算下，CAPR 在所有四个任务上达到或超越了当前最优（d-TreeRPO）。特别是在 Sudoku 上，以不到三分之一的每步计算成本达到 93.0% 的准确率。
2. **计算-精度折中**：CAPR 的生成成本仅为平展 rollout 的 0.75 倍、树 rollout 的 0.6 倍，同时获得了媲美树方法的细粒度优势。
3. **组件贡献排序**：
   - **Block Critic** 是最关键的单项，单独使用即使效果有限，但与 Branch & Prune 结合后奖励峰值从 0.27 跃升至 0.85。
   - **自蒸馏** 将已求解组的零方差死数据转化为有用信号，平滑梯度尖峰。
   - **卡方正则化** 有效抑制 token 级 log-ratio 尖峰，防止稀疏奖励下的过优化。
4. **跨骨干迁移性**：从密集 LLaDA-8B 到 MoE-7B，同一套超参数无需调优即可取得一致提升，表明方法具有通用性。
5. **训练稳定性**：参考 KL 保持在 0.4 以下（除 MoE 上某些任务稍高），价值头 MSE 和 χ² 正则项均处在受控范围，表明政策未发生有害漂移。
