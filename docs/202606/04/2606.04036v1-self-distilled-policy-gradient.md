## 摘要
在策略自蒸馏，即语言模型基于特权上下文来监督自己的生成，为稀疏奖励强化学习提供了有希望的密集监督来源。实际上，它可以实例化为一个辅助的全词汇学生到教师的逆向Kullback-Leibler散度损失。因此，我们提出了SDPG，一个自蒸馏策略梯度框架，它结合了组相对验证器优势与归一化标准差、精确的全词汇在策略自蒸馏以及参考策略KL正则化。实验上，SDPG在稳定性和性能上优于RLVR和自蒸馏基线。代码可在https://github.com/lauyikfung/SDPG获取。

## Abstract
On-policy self-distillation, where a language model conditions on privileged context to supervise its own generations, is a promising source of dense supervision for sparse-reward reinforcement learning. Actually, it can be instantiated as an auxiliary full-vocabulary student-to-teacher reverse Kullback-Leibler divergence loss. We therefore propose SDPG, a self-distilled policy-gradient framework that combines group-relative verifier advantages with normalized standard deviation, exact full-vocabulary on-policy self-distillation, as well as reference-policy KL regularization. Empirically, SDPG improves stability and performance over RLVR and self-distillation baselines. The code is available at https://github.com/lauyikfung/SDPG.

- **核心问题**：在面向推理任务（如数学、代码）的强化学习（RLVR）中，常使用规则验证器提供稀疏的序列级奖励，这导致模型难以辨别每个token的局部正确性，学习效率低。此外，早期训练中大量负优势信号会使模型不稳定甚至损害语言能力。
- **已有方法局限**：  
  - GRPO等RLVR方法：奖励稀疏，token间信用分配均匀。

  - 近期自蒸馏方法（如OPCD、OPSD、RLSD）：缺乏与验证器奖励的有效结合，或只做加权而未进行精确分布匹配，仍存在模式崩塌或探索不足问题。
- **整体含义**：本文提出自蒸馏策略梯度框架（SDPG），通过将精确的全词汇on-policy自蒸馏与验证器奖励、参考策略KL正则化有机结合，提供密集的token级监督，同时保持RLVR的探索和选择优势，最终提升稀疏奖励场景下的训练稳定性和最终性能。

## 2. 论文提出的方法论
### 核心思想
- 将同一模型在**无特权上下文**（学生）和**有特权上下文**（教师）下形成的两个分布之间的反向KL散度作为辅助损失，实现全词汇自蒸馏。该损失在固定前缀下等价于一个带有中心化对数比的策略梯度形式（Proposition 3.1）。
- 将自蒸馏损失与验证器奖励（组相对优势）及固定参考策略的KL正则化（使用非归一化KL）组合，获得整体目标函数。

### 关键技术细节
- **全词汇on-policy自蒸馏**：在每个采样前缀上计算精确的 `D_KL(p_t || sg[q_t])`，其中 `p_t` 为学生分布（仅输入x），`q_t` 为教师分布（带特权上下文c）。
- **正优势门控（Positive Advantage Gating）**：仅在验证器优势为正的轨迹上施加自蒸馏损失，避免在错误轨迹上强化局部合理但全局错误的生成。
- **β调度（Warmup-Decay Schedule）**：蒸馏系数β先暖身后衰减，防止早期噪声和后期过度约束。
- **参考策略KL正则化**：采用**非归一化KL（UKL）**（包含质量修正项）分别实现前向（UFKL）和反向（URKL）正则化，公式给出对应梯度与可微替代损失，避免标准KL在on-policy下的偏差。
- **整体损失**：`L_SDPG = L_out + β(k)*L+_OPD + α L_K(π_θ, π_ref)`，其中`L_out`为基于验证器奖励的策略梯度（无PPO裁剪，使用组相对优势），`L+_OPD`为门控自蒸馏损失，`L_K`为UKL正则化。

### 算法流程
1. 采样一批prompt和特权上下文。
2. 对每个prompt，从当前学生策略采样G个响应。
3. 获取二进制验证器奖励，计算组相对优势，生成门控掩码（优势>0）。
4. 对每个采样前缀，计算学生分布和教师分布，并计算全词汇KL损失。
5. 组合三个损失，更新策略参数。

## 6. 论文的主要结论与发现
- SDPG（两种正则化变体）在AIME24/25和AMC23的最终准确率和峰值准确率上均一致优于GRPO和RLSD。
- SDPG-UFKL在训练过程中保持较高动作熵，避免RLSD出现的熵崩塌现象，说明自蒸馏与KL正则化共同作用增强了探索稳定性。
- 正优势门控和β调度有效防止噪声教师信号造成干扰。
- 在更小模型（Qwen3-1.7B）上复现了类似增益，且纯自蒸馏基线OPCD出现训练后期崩塌，进一步支持SDPG的必要性。
- 消融实验表明：OPD项主要贡献早期快速收敛，KL正则化则维持策略稳定性和合理响应长度。

- **实验扎实**：在多种模型规模、多个基准、多组对比方法及完整消融下验证效果，并呈现训练动态以解释行为差异。

## 8. 不足与局限
- **特权信息依赖**：需要外部生成（如Gemini 2.5 Pro）提供特权上下文（正确答案和解题步骤），在实际部署中可能无法获得或质量不可控，引入额外成本和偏差。
- **计算开销**：全词汇KL计算需要遍历整个词汇表，对每个前缀都做一次前向传播并计算softmax，相比仅采样token的方式增加计算量。
- **超参数调优**：β调度（Twarm、Tdecay）和α需要额外调节，对不同任务或模型可能敏感。
- **评估范围有限**：仅测试数学推理任务（AIME、AMC），未推广到代码、通用问答或更复杂的搜索/规划任务。

- **稳定性保障仍有限**：当特权信息有明显噪声或模型过小时，正优势门控可能过于激进，错过有用教师信号；或β调度不当仍可能影响训练。
