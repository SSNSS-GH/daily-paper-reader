## 摘要
流模型和扩散模型在许多模态中生成高质量样本；然而，在推理过程中，由于对底层微分方程进行数值积分，需要多次网络评估。流映射通过直接学习微分方程的解映射来缓解这一问题，从而实现少步采样。然而，当前方法仅限于逼近常微分方程的解映射。这些方法可用于学习随机微分方程的转移核，从而获得恢复过程边缘分布（弱收敛）而非解路径（强收敛）的解映射。我们提出强随机流映射（SSFMs）作为学习加性噪声随机微分方程强解映射的新框架，直接将确定性流映射推广到随机设置。此外，引入了布朗运动的多项式逼近，并证明其路径收敛。这些结果为扩散模型的解映射提供了无模拟训练目标。我们证明，SSFMs在图像生成上优于先前的随机流映射方法，并实现了分子系统的少步采样。

## Abstract
Flow and diffusion models generate high-quality samples in many modalities; however, many network evaluations are required during inference due to numerical integration of an underlying differential equation. Flow maps alleviate this problem by learning the solution map of the differential equation directly, enabling few-step sampling. Yet, current methods are restricted to approximating the solution map of ODEs. These methods can be used to learn the transition kernel of an SDE, thereby obtaining a solution map that recovers the marginal distributions of the process (weak convergence) rather than the solution path (strong convergence). We propose Strong Stochastic Flow Maps (SSFMs) as a novel framework for learning the strong solution map of additive-noise SDEs, directly generalizing deterministic flow maps to the stochastic setting. Further, a polynomial approximation to Brownian motion is introduced and shown to converge pathwise. These results enable a simulation-free training objective for the solution map of diffusion models. We demonstrate that SSFMs outperform previous stochastic flow map methods on image generation and enable few-step sampling of molecular systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：流模型和扩散模型通过神经微分方程生成高质量样本，但推理时需要多次网络评估（NFE）进行数值积分，导致计算成本高。现有流映射方法直接学习ODE的解映射，实现少步采样，但仅限于确定性常微分方程，无法处理随机微分方程。
- **问题**：对于随机微分方程，先前的工作（如弱随机流映射）仅能逼近SDE的转移核，恢复过程的**边际分布（弱收敛）**，而非**路径解（强收敛）**。这限制了路径可观测量的估计，也无法与底层随机路径保持一致。
- **含义**：本文提出**强随机流映射（SSFMs）**，直接学习加性噪声SDE的**强解映射**（Itô映射），将确定性流映射自然推广到随机场景，实现路径一致的少步采样。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **Itô映射**：SDE的解映射记为 \(\Psi_{s,t}(X_s, W_{[s,t]})\)，它同时依赖于初始状态和布朗运动路径。SSFMs通过神经网络参数化该映射，训练后可在任意时间步直接预测解，无需迭代积分。
- **强收敛**：对于同一布朗路径，不同步数下的采样结果应一致（Pathwise一致），而弱方法每次独立采样边际分布，路径不同。

### 2.2 关键技术细节
- **参数化形式**：采用Euler-Maruyama形式的参数化：
  \[
  \Psi_{s,t}(X_s, W_{[s,t]}) = X_s + f_{s,t}(X_s, W_{[s,t]})(t-s) + g_{s,t}(W_{[s,t]})(W_t - W_s)
  \]
  \(f_{s,t}\) 和 \(g_{s,t}\) 分别近似归一化漂移积分和扩散积分。
- **布朗运动多项式逼近**：对布朗路径 \(W_{[s,t]}\) 进行 \(N\) 阶勒让德多项式展开，系数 \(I^{(n)}_{s,t}\) 独立正态分布，且满足闭式Chen关系（允许在子区间上组合系数）。定理3.4证明该逼近在α-Hölder距离下路径收敛。
- **训练目标**：自蒸馏损失，包含两项：
  - **匹配损失** \(L_{f,g}\)：迫使 \(f_{t,t}\) 和 \(g_{t,t}\) 逼近真实漂移和扩散系数。
  - **蒸馏损失** \(L_D\)：强制满足半群条件（semigroup property），即两步映射结果与直接映射一致。
- **算法**：训练时交替使用小步Euler-Maruyama步骤（匹配）和大步自蒸馏步骤。实现无模拟训练（仅需条件漂移/扩散系数，无需模拟完整轨迹）。
