## 摘要
Sure Independence Screening and Sparsifying Operator (SISSO) 框架是一种强大的符号回归方法，用于从大型非线性特征空间中提取紧凑且可解释的描述符。然而，标准 SISSO 是确定性的：它返回单个描述符和点预测，而不量化描述符选择、回归系数或预测中的不确定性。本文提出了一种概率扩展，其中保持确定性的SIS阶段以保留可扩展性，而将SO阶段重新表述为对SIS筛选后的支持空间进行贝叶斯推断。由此产生的确定性SIS/贝叶斯SO框架为竞争性的描述符支持、特征包含概率、贝叶斯模型平均预测和预测可信区间提供后验概率，同时在最大后验极限下恢复标准SISSO的确定性SO描述符。应用于$X_2YZ$ Heusler合金磁矩数据集时，该方法在五折交叉验证RMSE上略有改进，且95%预测区间的经验覆盖率接近名义值。更重要的是，后验概率揭示了竞争性的、物理相关的符号描述符家族，而这些在确定性分析中会显得人为唯一。这些结果表明，确定性SIS/贝叶斯SO可以作为SISSO的不确定性感知诊断扩展：一种在小数据材料回归问题中评估描述符置信度、稳定性和非唯一性的工具。

## Abstract
The Sure Independence Screening and Sparsifying Operator (SISSO) framework is a powerful symbolic-regression method for extracting compact and interpretable descriptors from large nonlinear feature spaces. However, standard SISSO is deterministic: it returns a single descriptor and point prediction, without quantifying uncertainty in descriptor selection, regression coefficients, or predictions. Here we introduce a probabilistic extension in which the sure independence screening (SIS) stage is kept deterministic to preserve scalability, while the sparsifying operator (SO) stage is reformulated as Bayesian inference over the SIS-screened support space. The resulting deterministic-SIS/Bayesian-SO framework yields posterior probabilities for competing descriptor supports, feature-inclusion probabilities, Bayesian-model-averaged predictions, and predictive credible intervals, while recovering the deterministic SO descriptor of standard SISSO in the maximum-a-posteriori limit. Applied to an $X_2YZ$ Heusler-alloy magnetic-moment dataset, the approach gives modest improvements in five-fold cross-validation RMSE and near-nominal empirical coverage of the 95$\%$ predictive intervals. More importantly, the posterior exposes competing, physically related symbolic descriptor families that would appear artificially unique in a deterministic analysis. These results suggest that deterministic-SIS/Bayesian-SO can be used as an uncertainty-aware diagnostic extension of SISSO: a tool for assessing descriptor confidence, stability, and non-uniqueness in small-data materials regression problems.

# 论文深度结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

-   **出发点**：符号回归，特别是SISSO框架，是材料科学中一种强大的工具，能够从海量非线性特征空间中提取出紧凑、可解释的物理描述符（descriptor）。然而，标准SISSO是一个**确定性**的方法，它只输出一个最优描述符和对应的点预测，**无法量化选择过程和预测中的不确定性**。
-   **核心问题**：在小数据、高噪音的材料数据集场景中，多个高度相关的符号描述符可能都能很好地拟合数据，仅输出单一解会掩盖这种竞争关系和不确定性，限制了模型在科学发现中的可靠性。
-   **论文目标**：为了解决上述不确定性量化问题，本文提出一种概率扩展方法，在尽量保留SISSO计算效率和可解释性的基础上，为描述符选择、回归系数和预测提供后验概率估计。
-   **研究意义**：该工作将SISSO从一个纯确定性的管道扩展为不确定性感知的诊断工具，为材料科学家提供了评估描述符稳定性和非唯一性的新视角，特别适用于小样本回归问题。

## 2. 方法论：核心思想与技术细节

本文将SISSO的两阶段流程（SIS + SO）进行了**解耦式**改造，其核心思想是：**保持SIS阶段的确定性以维护其计算可扩展性，仅将SO阶段（稀疏优化）替换为贝叶斯推断**。

-   **阶段一：确定性SIS（Sure Independence Screening）**
    -   **操作**：保留原始SISSO的确定性筛选步骤。基于相关性（如与目标或残差的相关性）对巨大的符号特征库进行排序，只保留排名前K的特征。
    -   **目的**：将待探索的特征空间从天文数字压缩到一个可计算的、小规模的特征子集。
-   **阶段二：贝叶斯SO（Sparsifying Operator）**
    -   **核心思想**：在SIS筛选后的特征子集上，将寻找最优稀疏描述符的问题视为一个模型选择问题。利用贝叶斯公式，计算每个候选描述符（特定特征子集 `γ`）的后验概率。
    -   **数学推导**：
        1.  **模型**：采用高斯线性模型 `y = Φ(γ)βγ + ε`。
        2.  **先验**：为系数 `βγ` 和描述符支持 `γ` 设定先验分布。对系数使用高斯共轭先验 `βγ ~ N(0, τ²I)`。
        3.  **边际似然**：通过对系数 `βγ` 积分，可以得到闭合形式的**边际似然** `p(y | γ)`，它衡量了在给定支持γ下，数据y被解释的可能性。
        4.  **后验概率**：利用贝叶斯公式计算支持`γ`的后验概率：
            `p(γ | D) ∝ p(y | γ) * p(γ)`。
            其中，`p(γ)`是**支持先验**，是该方法的一个可调关键设计。
    -   **关键先验设计**：
        -   **均匀先验**：最通用，对所有大小为d的支持赋予相等概率。
        -   **相关性-多样性先验**：偏好包含高相关性（高SIS分数）特征但特征之间低相关性的支持。旨在鼓励选择“好”且“不冗余”的特征组合。
        -   **Slater-Pauling（SP）先验**：一种弱物理先验，用于特定的Heusler合金案例。它鼓励描述符由一个“主链”（类似电子计数特征）和一个“残差校正”特征组成，组织方式更符合物理直觉，但不强制遵循理想规则。
    -   **预测与推断**：
        -   **贝叶斯模型平均（BMA）**：最终的预测是所有可能支持预测的加权平均，权重为各自的后验概率。这提供了不确定性量化的预测值和预测可信区间。
        -   **特征包含概率（PIP）**：某个特征被包含在真实描述符中的后验概率，用于评估特征的稳定性。
        -   **恢复确定性解**：在最大后验（MAP）极限下，该方法可以恢复标准SISSO的确定性SO解。

-   **数据集**：X₂YZ全Heusler合金磁矩数据集，包含88种化合物（38个Co基、32个Fe基、18个Ni基）。输入特征为18个位点分辨的元素描述符（如电离能、电负性、价电子数等）。
-   **基准方法**：标准SISSO的确定性SIS+SO流程。它被作为对比的基线。
-   **对比方法**：本文提出的贝叶斯SO方法，使用三种不同支持先验（均匀、相关性-多样性、Slater-Pauling）进行对比。
-   **评估指标**：
    -   **预测精度**：五折交叉验证的均方根误差（RMSE）。
    -   **不确定性校准**：95%预测区间对真实值的经验覆盖率。
    -   **描述符稳定性**：特征包含概率（PIP）、后验概率分布。
-   **实验设置**：SISSO计算的符号库规模巨大（~2.4亿个表达式），SIS筛选后保留K=400（d=2）或K=300（d=3）个特征，枚举所有大小为d的支持（d=2时为~8万个，d=3时为~450万个）。实验对比了d=2和d=3两种描述符维度。

## 6. 主要结论与发现

1.  **不确定性量化**：本文提出的确定性SIS / 贝叶斯SO框架成功地为SISSO符号回归提供了不确定性量化，包括后验描述符概率、特征包含概率和预测可信区间。
2.  **预测性能提升**：在Heusler合金磁矩预测上，贝叶斯模型平均（BMA）的验证集RMSE**略优于**标准SISSO的确定性点预测，表明模型平均有助于减少方差。
3.  **逼近期望的覆盖率**：95%预测区间的经验覆盖率非常接近95%的名义值，证明该方法提供的不确定性估计是校准良好的，是可靠的。
4.  **揭示描述符稳定性**：后验分析揭示了一个关键发现：标准SISSO选择的确定性描述符**只是**一个更大的、统计上具有竞争力的描述符家族中的**一个代表**。例如，特征8总是首选，但第二次元在特征201和203之间摇摆不定。这揭示了“描述符非唯一性”这一重要现象。
5.  **先验的影响有限**：在d=2的情况下，不同先验（均匀、相关性-多样性、Slater-Pauling）下的RMSE几乎相同，表明**关键提升来自于贝叶斯BMA，而非先验工程**。Slater-Pauling先验的主要价值在于为后验组织提供了一个更物理的解释视角。
6.  **物理洞察**：结果印证了Heusler合金磁性与X位点体积、价电子数以及Y/Z位点之间的价电子和体积对比强相关的物理图像。

## 7. 方法的优点（亮点）

1.  **保留可扩展性**：通过保持SIS步骤的确定性，避免了在全特征空间进行贝叶斯推断的巨大计算负担，使得方法在计算上是可行且高效的。
2.  **直接量化不确定性**：首次为SISSO这类确定性符号回归方法提供了完整的贝叶斯不确定性框架，弥补了其关键缺陷。
3.  **引入贝叶斯模型平均（BMA）**：使用BMA进行预测，不仅给出了点预测，还提供了校准良好的预测区间，比单一的确定性模型更稳健。
4.  **基于物理的先验（选项）**：提供了引入弱物理先验（如Slater-Pauling先验）的范本，在保持数据驱动的同时，融入了先验知识，增强了结果的可解释性和可信度。
5.  **诊断工具价值**：工作方法被定位为**诊断工具**，这比单纯追求更低RMSE更有科学意义。它帮助用户发现数据中的关键不确定性，避免过度解读单一最优描述符。

## 8. 不足与局限

1.  **先验设计的依赖性**：虽然论文证明了均匀先验已足够好，但引入物理先验（如Slater-Pauling）需要领域知识，并非所有场景都适用。不同领域可能需要设计不同的物理先验，这增加了应用的复杂性。
2.  **实验覆盖范围有限**：仅在单一材料数据集（Heusler合金）上进行了验证。它后续需要在更多样化的材料问题、不同噪音水平、不同数据规模下进行测试，以证明其**泛化能力**。
3.  **缺少对比基准**：未与其它流行的符号回归不确定性方法（如基于变分推理的神经网络、梯度提升机的不确定性估计等）进行对比。无法判断其在性能和校准上的相对优劣。
4.  **计算复杂性**：虽然比全空间枚举高效，但后验枚举的规模仍随SIS保留的特征数K和支持维度d组合增长。对于d很大或K很大的情况，精确枚举可能仍然计算不可行，需要借助近似采样方法。
5.  **模型假设**：贝叶斯模型部分假设了高斯线性模型，这可能是对复杂物质规律的一个简化。对于非线性关系或更复杂的分布结构，该框架可能需要扩展。
